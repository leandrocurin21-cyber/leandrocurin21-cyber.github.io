# Política de privacidad — FP STREAM (LNC Lab)

Última actualización: 17/11/2026

**Qué datos usa.** FP STREAM usa la API de datos de YouTube solo para leer el estado de las transmisiones en vivo de los canales que su dueño autoriza y para poner esos vivos en Público.

**Dónde se guardan.** Los permisos de acceso se guardan cifrados únicamente en la computadora donde corre la herramienta. No se guardan en servidores de LNC Lab ni se comparten con terceros.

**Uso de datos de Google.** El uso de la información recibida de las API de Google cumple con la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

**Cómo quitar el acceso.** En cualquier momento desde https://myaccount.google.com/permissions
